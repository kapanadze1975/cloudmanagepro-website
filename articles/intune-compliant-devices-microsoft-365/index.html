How to Require Intune-Compliant Devices for Microsoft 365

A practical CloudManagePro guide for understanding how Intune device compliance and Microsoft Entra Conditional Access can work together to protect access to Microsoft 365.

Technical Guide•Intermediate•CloudManagePro
✓Compliant
Microsoft 365
🔒
About this guide This article explains how to require devices managed by Microsoft Intune to be evaluated as compliant before granting access to Microsoft 365 resources using Microsoft Entra Conditional Access. It covers prerequisites, configuration, validation, troubleshooting, rollout recommendations, and best practices.

Overview

When you require Intune-compliant devices for Microsoft 365 access, Microsoft Entra Conditional Access evaluates the device compliance state reported by Microsoft Intune and enforces a grant control that requires the device to be marked as compliant before access is allowed.

Prerequisites

  • Devices must be enrolled in Microsoft Intune and subject to Intune device compliance policies: https://learn.microsoft.com/en-us/intune/device-security/compliance/overview
  • Conditional Access relies on Microsoft Entra licensing: https://learn.microsoft.com/en-us/entra/fundamentals/licensing
  • Users must have required Intune licenses: https://learn.microsoft.com/en-us/intune/fundamentals/licensing
  • Administrators should use Intune RBAC and Conditional Access roles: https://learn.microsoft.com/en-us/intune/fundamentals/role-based-access-control/ref-built-in-roles

Configuration

Configure Intune compliance policies and a Conditional Access policy that includes the grant control "Require device to be marked as compliant." See Microsoft guidance: https://learn.microsoft.com/en-us/intune/device-security/compliance/create-policy and https://learn.microsoft.com/en-us/entra/identity/conditional-access/concept-conditional-access-grant.

Prepare the pilot

Start with pilot groups to verify enrollment and compliance evaluation.

Create and assign compliance policies appropriate for your environment.

Configure Conditional Access

Create a CA policy targeting users and apps and include the grant control "Require device to be marked as compliant."

Testing & validation

Use Conditional Access report-only mode and the What If tool to evaluate policy impact before enforcement: report-only, What If tool.

Troubleshooting

  • Confirm devices are enrolled and receiving compliance evaluations: Intune compliance
  • Verify Intune licensing: Intune licensing
  • Confirm Conditional Access licensing: Entra licensing

Best practices

  • Validate policies in report-only mode and with the What If tool before enforcement.
  • Use least-privilege administrative roles and governance for role assignments.
  • Plan phased rollouts and ensure licensing requirements are met.
  • Monitor and address legacy authentication.

FAQ

Can Conditional Access use Intune compliance state?

Yes. See: Intune + CA integration

Which grant control enforces Intune device compliance?

"Require device to be marked as compliant." See: grant controls
