How to Package and Deploy Win32 Apps with Microsoft Intune (.intunewin)

A practical guide for packaging Win32 applications into the .intunewin format, creating reliable detection rules, declaring dependencies and supersedence, optimizing Delivery Optimization settings, and troubleshooting common Intune deployment failures.

Technical Guide • Intermediate • CloudManagePro Last verified: September 5, 2026

Intune

Overview

This article explains how to prepare Win32 applications for deployment with Microsoft Intune by creating .intunewin packages using the Microsoft Win32 Content Prep Tool, authoring detection rules and requirements, declaring dependencies and supersedence relationships, configuring delivery optimization and distribution settings, and basic troubleshooting guidance for Intune Win32 app installations. All procedural steps reference Microsoft documentation and the Microsoft Win32 Content Prep Tool repository.

Prerequisites

  • Access to Microsoft Intune (appropriate admin role) and required licenses for device management.
  • Windows devices enrolled in Intune or targeted groups for deployment testing.
  • Microsoft Win32 Content Prep Tool to create .intunewin packages: https://github.com/microsoft/Microsoft-Win32-Content-Prep-Tool

Package Win32 apps as .intunewin

Use the Microsoft Win32 Content Prep Tool to create a single .intunewin file that contains the application installation files and metadata. Follow Microsoft guidance to prepare the source folder, specify the setup file and command-line, and create the .intunewin output:

  • Download the tool: https://github.com/microsoft/Microsoft-Win32-Content-Prep-Tool
  • Create the source folder with installer binaries and supporting files.
  • Run the content prep tool and provide the setup file, detection method parameters, and output path. See official docs: https://learn.microsoft.com/en-us/intune/app-management/deployment/create-win32-package

Create reliable detection rules

Detection rules tell Intune how to determine whether the app is installed on the client. Use file, MSI product code, or registry-based detection methods as appropriate for the application. Reference: https://learn.microsoft.com/en-us/intune/app-management/deployment/add-win32

Declare dependencies and supersedence

When apps require prerequisites, declare dependencies so Intune installs them first. Use supersedence to replace older app versions with new ones. Follow Microsoft's guidance on declaring dependencies and configuring supersedence during the Win32 app creation flow: https://learn.microsoft.com/en-us/intune/app-management/deployment/add-win32#step-6-supersedence

Optimize Delivery Optimization and distribution

Delivery Optimization settings can reduce bandwidth usage by enabling peer caching and limiting network impact. Configure Delivery Optimization and Intune distribution settings according to your network topology and Microsoft guidance: https://learn.microsoft.com/en-us/intune/device-configuration/templates/configure-delivery-optimization-windows

Troubleshooting Intune Win32 deployments

  • Review Intune Management Extension logs on the client for install status and return codes: https://learn.microsoft.com/en-us/intune/device-management/tools/management-extension-windows
  • Consult Intune Win32 app troubleshooting documentation and common error code references: https://learn.microsoft.com/en-us/intune/app-management/deployment/troubleshoot-win32 and https://learn.microsoft.com/en-us/troubleshoot/mem/intune/app-management/troubleshoot-win32
  • Map Intune return codes to actionable guidance using Microsoft Graph and documentation: https://learn.microsoft.com/en-us/graph/api/resources/intune-apps-win32lobappreturncode?view=graph-rest-1.0
